Depuis l'application

Dans Paramètres > Contact/Assistance, votre message nous parvient avec les informations techniques qui nous aident à résoudre le problème plus vite.

Mot de passe oublié ?

Sur l'écran de connexion, touchez « Mot de passe oublié » et saisissez l'e-mail de votre compte. Vous recevrez un code à 6 chiffres pour créer un nouveau mot de passe.
